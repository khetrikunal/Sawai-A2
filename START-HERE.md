# Sawai Gir Amrut - Complete Website Codebase

This export contains the exact completed cinematic homepage source from revision f8a29f0, including all tracked project files, vendored workspace packages, source photographs, optimized campaign assets, video files, fonts, configuration and dependency lockfile.

## Run locally

Requirements: Node.js 22 or newer and Bun.

```bash
cd app
bun install --frozen-lockfile
bun run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Validate and build

```bash
cd app
bun run typecheck
bun run check:ui
bun run build
```

The default production build contains the server-rendered Cloudflare Worker in app/dist/server and browser assets in app/dist/client. Vercel builds use Nitro and emit the Vercel Build Output API files in app/.vercel/output. Build output and installed node_modules are excluded from this export and are regenerated by the commands above.

## Deploy on Vercel

Create a Vercel project with `app` as its Root Directory. The app's `vercel.json` selects the TanStack Start framework preset and configures the site's security headers. Vercel builds the app with Nitro as a serverless function; the existing default build remains configured for Cloudflare Workers. The vendored `fnf` and `quanta` directories are workspace libraries, not separate deployable services, and the homepage does not make service-to-service calls.

For local Vercel development, run `vercel dev` from `app`.

- refs/source/: source campaign images and footage used in the homepage.
- app/design-brief.md and app/verification.md: creative decisions and completed checks.

## Ordering and prices

The homepage purchase CTA opens a WhatsApp enquiry to the phone number supplied in the original project. Size and quantity are included in the draft. It does not automatically send a message or collect payment. Catalogue prices come from the supplied project; the team confirms current prices and availability before payment.

## Media and deployment

No new AI-generated campaign imagery was produced: Higgsfield generation was blocked by account restrictions. The hero film uses a subtle camera movement derived from the original jar photograph, and the pouring film is trimmed from the supplied footage.

The website was deployed at https://sawai-ghee.higgsfield.app. The platform reported a successful deployment, but an unauthenticated access check returned HTTP 401. Local development does not require public access to that hosted URL.

The Cloudflare deployment configuration contains platform placeholders. Configure your own Worker name, domain and bindings if deploying outside Higgsfield. The marketing homepage has no database or payment integration. Vendored platform scaffolding is included to keep the original project and build complete; it is not linked from the homepage.
